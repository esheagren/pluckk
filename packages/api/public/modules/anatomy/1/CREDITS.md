# Artwork in the anatomy module

The figures are adapted from illustrations on Wikimedia Commons: labels and editor data removed,
mirrored halves expanded, and each named part tagged so it can be highlighted and clicked.
Adaptations of CC BY-SA works are offered under the same licence.
